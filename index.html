Marketmailer

A lightweight EVE Online market watcher that polls the ESI market endpoints, stores orders locally in SQLite, and surfaces arbitrage opportunities — the best remote sell orders to instantly flip into the Jita buy wall. They're magically profitable! ❤️⭐🍀🌙

01 · Pipeline

How it works

Three stages between EVE's market data and the money-making signal on your screen.

1

Poll ESI markets

Per-region pollers fetch market orders from the ESI API with dynamic page scaling and exponential backoff. ETag caching means unchanged regions are skipped in a single request.

ESI → ETag cache → market pollers
2

Store locally

Orders land in a single SQLite file (WAL mode) alongside resolved EVE names for items, systems, regions and stations. Migrations run automatically on every boot.

SQLite · market.db · auto-migrate
3

Surface the edge

Queries rank remote sell orders that undercut the Jita buy wall, weighted by profit per unit and available volume. Readable on the console or in your Discord server.

SQL pivot → arbitrage ranked → you
02 · Arsenal

Features

Everything tuned for one job: buying low in the regions and selling high in Jita.

Benefits / Consumer Statements

  • SPREAD SCANNER: A frosted-simple pipeline that finds the single best remote sell order you can instantly flip into Jita's buy wall, ranked by instant_sell_profit.
  • UNDERCUT RADAR: The top-100 items whose remote sell price beats Jita's best buy, ordered by margin — your shopping list for station trading runs across all watched regions.
  • LAZY NAME RESOLUTION: No static data dumps. Item, system, region and station names resolve on demand from ESI into cached tables.
  • GLUTEN-FREE CONCURRENCY: A per-region GenServer tree with dynamic page scaling and supervisory restarts that survive transient ESI failures.
  • CONTAINS: One SQLite database of market orders, etags, and names, ready to eat — or to query — any time. Perfect for instant arbitrage or a lunch-box trading run.

Program Technologies Used

The runtime, libraries and tooling the watcher is built on.
TechnologyUsed for
🌈Elixir · OTP BEAM runtime, GenServer/Supervisor trees and OTP releases — the whole app. ~> 1.19

Also in the build: Playwright (Janice chart captures) · Castle (hot upgrades) · Taskfile + Docker (prod daemon) · Quokka + HendricksFormatter (dev formatter).

03 · Launch

Quick start

From clone to arbitrage feed in three commands.

mix setup

Install deps, create the SQLite database and run migrations.

task start

Run latest tree as prod release daemon (restarts when stale; survives terminal close).

task dev

Interactive shell with the app started — isolated dev.db + :4001, safe alongside prod.

task live:update

Hot-upgrade prod when code changed (patch-bump + appup + release); no-op otherwise.

mix ecto.migrate

Manual migration control (migrations also run automatically on every boot).

VariablePurpose
DISCORD_TOKENEnables the optional Discord bot. Missing/invalid → bot skipped with a warning.

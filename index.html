Marketmailer

A lightweight EVE Online market watcher that polls the ESI market endpoints, stores orders locally in SQLite, and surfaces arbitrage opportunities — the best remote sell orders to instantly flip into the Jita buy wall.

Get started See the features Add to Discord
01 · Pipeline

How it works

Three stages between EVE's market data and the money-making signal on your screen.

01

Poll ESI markets

Per-region pollers fetch market orders from the ESI API with dynamic page scaling and exponential backoff. ETag caching means unchanged regions are skipped in a single request.

ESI → ETag cache → market pollers
02

Store locally

Orders land in a single SQLite file (WAL mode) alongside resolved EVE names for items, systems, regions and stations. Migrations run automatically on every boot.

SQLite · market.db · auto-migrate
03

Surface the edge

Queries rank remote sell orders that undercut the Jita buy wall, weighted by profit per unit and available volume. Readable on the console or in your Discord server.

SQL pivot → arbitrage ranked → you
02 · Arsenal

Features

Everything tuned for one job: buying low in the regions and selling high in Jita.

Capsuleer briefing

  • SPREAD SCANNER: Finds the single best remote sell order you can instantly flip into Jita's buy wall, ranked by instant_sell_profit.
  • UNDERCUT RADAR: The top-100 items whose remote sell price beats Jita's best buy, ordered by margin.
  • SDE SNAPSHOT: Item, system, region and station names seeded from the official JSONL SDE — no per-request ESI name lookups.
  • CONCORD-GRADE CONCURRENCY: A per-region GenServer tree with dynamic page scaling and supervisory restarts that survive transient ESI failures.
  • ONE DATABASE: Market orders, etags, and names in a single WAL-mode SQLite file — query it any time.

04 · Launch

Quick start

From clone to a running arbitrage feed — three commands get you there.

task setup

Deps, migrations, the matching Playwright Chromium, and mix sde.import. The SDE seed creates the region rows the pollers are built from — skip it and no region manager starts.

task start

Build and run the latest tree as a detached prod release daemon. Survives terminal close and is a clean restart every time.

task live:update

Castle hot upgrade in two phases. Refuses on a dirty tree, writes the version bump + appup edge first, and never leaves the daemon down.

task stop

Kill-all switch: gracefully stops the prod daemon, then sweeps orphaned release processes.

task migrate

Manual migration control — migrations also run automatically on every boot.

task dev

Interactive shell with the app started — isolated priv/data/dev.db on :4001, safe alongside the prod daemon.
